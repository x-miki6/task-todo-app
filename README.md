# task-todo-app
A simple and responsive task management app built with HTML, CSS, and JavaScript.

# ToDo APP

## 概要
ToDo APP は、HTML・CSS・JavaScriptを使用して開発する、タスクToDo管理アプリです。

## 使用技術
- HTML
- CSS
- JavaScript

## 主な機能（実装予定）
・タスクの追加
・タスクの一覧表示
・タスクの編集・削除
・完了チェック
・タスクの絞り込み
・データの保存

## 起動方法
`index.html` をブラウザで開いて操作します。

## 開発状況
開発中 🚧

## 制作目的
HTML・CSS・JavaScriptの学習と、個人アプリ制作の練習を目的としています。
